# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/weather-app.git
```

---

## 2️⃣ Open Project Folder

```bash
cd weather-app
```

---

## 3️⃣ Add API Key

Open `scripts.js`

Replace:

```javascript
const apiKey = "YOUR_API_KEY";
```

with:

```javascript
const apiKey = "YOUR_REAL_API_KEY";
```

---

# 🔑 Get Free API Key

1. Visit:

```bash
https://openweathermap.org/api
```

2. Create account
3. Generate API key
4. Paste in `scripts.js`

---

# ▶️ Run Project

Open:

```bash
index.html
```

in your browser.
